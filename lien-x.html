Prove your X account owns this wallet

Two halves. The wallet names the account, the account publishes the signature. Neither half alone proves anything — and a self-declared handle proves nothing at all.

1 · which X account

It is the numeric id that gets signed, never the @handle. A handle can be abandoned and taken by someone else, who would then inherit your proof. The numeric id never changes hands.
⚠️ A browser cannot read it. Measured 2026-09-07: X serves the id only to platform.twitter.com — every other origin is refused by CORS. Get it with node prepare-lien-x.mjs <post-id> <wallet>, which reads it directly. The link below only confirms the handle, which a browser is allowed to read.

⚠️ This is a message signature, not a transaction: no funds move, no gas is paid, nothing is sent to any chain. It is still a signature — read it before accepting.

what this can and cannot say

it provesthis account and this key acknowledge each other, at the time you check
it does not provethat the holder is honest. A scammer can prove their own link perfectly well — this attributes, it never absolves.
it can vanishthe post can be deleted. A verification is valid on a date, never "for ever".
not coveredsmart-contract wallets (EIP-1271) do not sign like a key — they will read as NOT MEASURED, never as false.
